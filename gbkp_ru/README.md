# Набор скриптов резервного копирования для репозиториев Studio git (gbkp)
Этот скрипт bash автоматизирует процесс настройки оповещений по электронной почте и автоматического резервного копирования для устройства хранения.

## Установщик

 - Позволяет устанавливать получателей электронной почты для уведомлений.
 - Настраивает различные параметры для автоматического резервного копирования, такие как:
    - Имя USB-устройства
    - Префикс метки диска
    - Каталог резервного копирования
    - Частота резервного копирования (ежемесячно, еженедельно, ежедневно)
 - Проверяет и проверяет адреса электронной почты перед продолжением
 - Устанавливает необходимое программное обеспечение, если его еще нет.
 - Создает файл конфигурации (`gbkp.conf`) с указанными настройками.
 - Обновляет задание cron для запуска скрипта резервного копирования.
 - Настраивает параметры SMTP для оповещений по электронной почте.

## Основной скрипт

Приложение для резервного копирования Git-репозиториев с зеркалированием `rsync` 

### Описание

Приложение автоматизирует процесс резервного копирования Git-репозиториев с использованием инструментов rsync для зеркалирования и git для работы с репозиториями. Основная задача приложения — обеспечить регулярное и надежное резервное копирование репозиториев на внешние накопители, а также управление жизненным циклом созданных архивов. 

**Основные функции** 

 - Проверка наличия конфигурационного файла
   - Перед началом работы приложение проверяет наличие и правильность конфигурационного файла /etc/gbkp/gbkp.conf.

 - Отправка уведомлений
   - Отправляет электронные письма участникам команды за 10 минут до начала процедуры резервного копирования и после её завершения.

 - Проверка подключения USB-устройств
   - Проверяет подключение USB-SATA адаптера и наличие необходимых накопителей с определёнными метками.
         
 - Монтирование и подготовка дисков
   - Монтирует все найденные диски и создаёт необходимые директории для хранения резервных копий.
         
 - Клонирование и обновление репозиториев
   - Клонирует новые репозитории из списка /etc/gbkp/repo.list и обновляет существующие.
         
 - Архивирование и сжатие
   - Архивирует копии репозиториев с указанием даты и типа резервной копии (ежедневная, еженедельная, ежемесячная).
         
 - Удаление старых архивов
   - Удаляет старые резервные копии согласно настройкам в конфигурационном файле.
         
 - Зеркалирование данных
   - Синхронизирует данные между первичным диском и остальными дисками в группе.
         
 - Доступ по сети
   - Предоставляет временный доступ к резервным копиям по протоколу SMB для проверки и использования.
         
 - Отправка уведомлений о завершении
   - Отправляет уведомление о необходимости выключения адаптера USB-SATA, извлечения носителей и их помещения в сейф.
         
**Требования** 

 - Операционная система Linux.
 - Установленные инструменты: `git`, `rsync`, `sendmail`, `mpack`, `samba`.
 - Конфигурационный файл `/etc/gbkp/gbkp.conf` с необходимыми параметрами.
 - Список репозиториев для резервного копирования `/etc/gbkp/repo.list`.
 - Подключённые USB-накопители с метками, соответствующими настройкам.

**Конфигурационные параметры**

 - `EMAIL_TO`: Список адресов электронной почты для получения уведомлений.
 - `USB_DEV`: Идентификатор USB-устройства.
 - `DISK_LABEL_PREFIX`: Префикс меток дисков.
 - `BKP_DIR`: Имя директории для хранения резервных копий.
 - `INTERVAL`: Интервал резервного копирования (ежедневно, еженедельно).
 - `DAILY`: Количество сохраняемых ежедневных резервных копий.
 - `WEEKLY`: Количество сохраняемых еженедельных резервных копий.
 - `MONTHLY`: Количество сохраняемых ежемесячных резервных копий.

**Как работает:**

 1. Монтирование и синхронизация дисков:
    - Скрипт сканирует подключенные дики и монтирует те из них, чья метка соответствует заданному префиксу.
    - Каждый подключенный диск он синхронизирует с ведущим диском с помощью `rsync`.
 1. Запись:
    - Скрипт записывает все действия и потенциальные ошибки или предупреждения в лог-файл.
 1. Доступ через SMB:
    - Скрипт использует сгенерированный файл `smbd.conf`, чтобы дать доступ к скачанным репозиториям доступ заинтересованным в резервном копировании разработчикам.
 1. Отправка электронного сообщения:
    - Скрипт проверяет на наличие ошибок во время процесса и отправляет электронные сообщения в зависимости от этого.
 1. Отмонтирование и очистка:
    - Через час скрипт прекращает доступ по `smb` и отмонтирует внешние диски.
    - Отправляет электронное письмо, напоминая пользователям о необходимости перемещения внешних дисков из безопасное место.

**Дополнительные замечания:**

 - Скрипт требует прав `root` и использует определенные имена каталогов и конфигурационных файлов.
 - Переменная `BKP_DIR` должна быть определена, чтобы указать каталог, где хранятся резервы.
 - Переменная `EMAIL_TO` должна быть заполнена адресами электронных почт, чтобы получать уведомления.

**Возможности:**

 - Включает тщательную проверку адресов электронной почты.
 - Предоставляет обратную связь пользователю на протяжении всего процесса.
 - Предлагает четкое подтверждение перед внесением изменений.

Прежде всего, получите список репозиториев, которые вы хотите создать.

Чтобы получить список репозиториев в формате .json, вам нужно использовать gitlab api:
 - `https://your-gitlab-host/api/v4/projects`
Вы можете автоматизировать это, но я не вижу необходимости в этом шаге
 - После этого вам нужно сохранить файл .json в каталоге, назвав его так:
   - gbkp_YOUR-REPO-NAME.json
   скрипт найдет его как `gbkp*.json`

Второй шаг - запустите скрипт установки от суперпользователя.
 - `sudo ./install.sh`
 - Если вы хотите изменить параметры - измените файл `/etc/gbkp.conf`
 - Если вы хотите добавить список репозиториев к существующему - поместите новый файл в этот каталог и снова запустите скрипт установки с параметром `--add-json`
 - Если вы хотите изменить список репозиториев - поместите новый файл в этот каталог и снова запустите скрипт установки с параметром `--new-json`
